# AI Smart Timetable — ระบบจัดตารางเรียนและตารางสอนอัตโนมัติ

เว็บแอปจัดตารางเรียน/ตารางสอน (จันทร์–ศุกร์) ตรวจการชนกันของ **ครู ห้องเรียน กลุ่มนักศึกษา** รับไฟล์ Excel/CSV และเก็บข้อมูลบนคลาวด์ (Supabase) ไม่ต้องติดตั้งหรือ build ใดๆ

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด (หน้าจอ + อัลกอริทึมจัดตาราง) |
| `config.js` | ใส่ Supabase URL และ anon key |
| `supabase.sql` | สคริปต์สร้างตารางฐานข้อมูล |
| `vercel.json` | ตั้งค่า Vercel |

## วิธีใช้งานเบื้องต้น
1. เปิดเว็บ → หน้า **ภาพรวม** มีข้อมูลตัวอย่างจากโจทย์ใส่ไว้แล้ว
2. ดูผล **ขั้นตอนที่ 1: ตรวจสอบข้อมูล** (แจ้งข้อมูลซ้ำ/ขาด/อ้างอิงผิด)
3. กด **⚡ จัดตารางอัตโนมัติ** → ดูผลตรวจเงื่อนไข ✅/❌
4. ไปหน้า **ตารางเรียน/สอน** เลือกดูตามกลุ่ม ครู หรือห้อง พิมพ์หรือส่งออก CSV ได้
5. **โจทย์ท้าทาย:** ในหน้าภาพรวม เลือกครู (เช่น T01) + วัน (พฤหัสบดี) → *เพิ่มเงื่อนไขและจัดตารางใหม่*
6. แก้ข้อมูลเองได้ที่หน้า **จัดการข้อมูล** (ช่อง "ไม่สะดวก" เช่น `จ:P1`, `พฤ` = ทั้งวัน)

หากจัดไม่ครบ ระบบจะ **ไม่สร้างตารางที่ผิดเงื่อนไข** แต่แจ้งสาเหตุรายวิชาและแนวทางแก้ไข

## รูปแบบไฟล์นำเข้า (Excel/CSV)
Excel: ตั้งชื่อชีตเป็น `teachers`, `rooms`, `groups`, `courses`, `periods` (มีบางชีตก็ได้)
CSV: 1 ไฟล์ต่อ 1 ตาราง ระบบเดาประเภทจากหัวคอลัมน์ (ใช้ UTF-8)
ปุ่ม **ส่งออกข้อมูล (.xlsx)** ใช้เป็นไฟล์ต้นแบบได้

| ชีต | หัวคอลัมน์ |
|---|---|
| teachers | `id, name, skills, unavail, max` |
| rooms | `id, type, cap` |
| groups | `id, size` |
| courses | `id, name, teacher, group, n, room` (room = รหัสห้อง หรือประเภทห้อง) |
| periods | `id, start, end` |

## ตั้งค่าฐานข้อมูลคลาวด์ (Supabase ฟรี)
1. สมัคร https://supabase.com → New project
2. เมนู **SQL Editor** → วางเนื้อหา `supabase.sql` → Run
3. เมนู **Project Settings → API** คัดลอก `Project URL` และ `anon public key`
4. ใส่ใน `config.js` (หรือกดปุ่มสถานะคลาวด์มุมซ้ายล่างของเว็บแล้ววางค่า)
5. เมื่อเชื่อมต่อแล้วสถานะเป็น "เชื่อมต่อคลาวด์แล้ว" และทุกการแก้ไขจะซิงก์อัตโนมัติ

> ⚠ นโยบายใน `supabase.sql` เปิดให้ทุกคนที่มี anon key อ่าน/เขียนได้ (เหมาะกับการแข่งขัน/สาธิต) ถ้าใช้งานจริงควรเพิ่มระบบล็อกอินแล้วจำกัดสิทธิ์

## Deploy ขึ้น Vercel
**วิธี A: CLI (เร็วสุด)**
```bash
npm i -g vercel
cd timetable-app
vercel --prod
```
(ตอบ Enter ตามค่าเริ่มต้น; Framework = Other, ไม่ต้องมี build command)

**วิธี B: ผ่าน GitHub**
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo
2. https://vercel.com/new → Import repo → Deploy

## ทดลองบนเครื่อง
```bash
npx serve .
```
เปิด http://localhost:3000
